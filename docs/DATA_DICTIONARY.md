# Data dictionary

This file covers every dataset in the repo: where it came from, what each
column means, and which code reads or writes it. The equations are in
[PHYSICS.md](PHYSICS.md).

## Rules

1. **Raw data is read-only.** Never edit, re-save, reformat or replace
   `data/sparc/table2.dat`. `analysis/sparc_data.py` stops with an error if
   its checksum changes.
2. **Everything else is generated** from the raw data by a script listed below,
   so it can be rebuilt at any time.
3. **One copy of each dataset.** Don't add a second SPARC file. Read through
   `analysis/sparc_data.py` instead.
4. **Never invent measurements.** If a value is missing, leave it missing and
   say so.
5. **Keep observations and models apart.** Only `V_obs` and `e_V_obs` are
   measurements. Anything called V_bar, V_halo, V_model, V_nfw_halo or
   V_total_model is a model prediction.

## Raw: `data/sparc/table2.dat`

| | |
|---|---|
| Source | SPARC mass models, Lelli, McGaugh & Schombert (2016), AJ 152, 157. CDS catalogue J/AJ/152/157, table2 ("Mass models") |
| Downloaded | 2026-09-25, from VizieR (vizier.cds.unistra.fr), as the tab-separated export. The date is in the file header |
| Format | VizieR TSV: `#` comment lines, then a column-name line, a units line, a dashed line and the data rows. Tab-separated, with mixed CRLF/LF line endings |
| Size | 3391 rows, 175 galaxies |
| Checksum | SHA-256 (line endings normalised to LF) `40144d85…8995`, stored in full in `SPARC_SHA256` in `analysis/sparc_data.py` |
| Loader | `analysis/sparc_data.py` (`load_table`, `galaxy_rows`) checks the checksum, header, column count and the value ranges VizieR publishes |

Each row is one radius of one galaxy.

| Column | Field in `SparcRow` | Units | Meaning |
|---|---|---|---|
| Name | `name` | – | Galaxy identifier, e.g. `NGC3198` |
| Dist | `dist_mpc` | Mpc | Distance SPARC assumes for the galaxy. All its radii and masses depend on it |
| Rad | `rad_kpc` | kpc | Galactocentric radius |
| Vobs | `v_obs_kms` | km/s | **Observed** circular speed |
| e_Vobs | `e_v_obs_kms` | km/s | 1σ uncertainty of Vobs |
| Vgas | `v_gas_kms` | km/s | Speed the gas alone would give. **Can be negative** (range −17 to 87). Use V_gas·\|V_gas\| |
| Vdisk | `v_disk_kms` | km/s | Speed the stellar disk alone would give for **M/L = 1** at 3.6 μm. Multiply its square by Υ_disk |
| Vbulge | `v_bulge_kms` | km/s | Same for the bulge (M/L = 1). Multiply its square by Υ_bulge. It is 0 for bulgeless galaxies |
| SBdisk | `sb_disk` | L☉/pc² | Disk surface brightness (not used by the physics) |
| SBbulge | `sb_bulge` | L☉/pc² | Bulge surface brightness (not used) |

**Galaxies used:** NGC 3198 (43 radii, 6 with small negative V_gas),
NGC 2403 (73 radii) and NGC 7331 (36 radii, 7 with negative V_gas). The site's
presets are listed in `GALAXY_PRESETS` in `generate_interactive_html.py`.

**If the file is ever lost:** restore it with `git checkout -- data/sparc/table2.dat`.
Downloading a fresh copy from CDS gives a different layout and checksum, so
record the new provenance here and update `SPARC_SHA256` only after checking
that the numbers match.

## Generated by the website generator

`python generate_interactive_html.py` reads `table2.dat` only.

| File | Contents |
|---|---|
| `galaxies.js` | `window.GALAXIES`: for each preset, `radius_kpc`, `v_obs_kms`, `v_obs_err_kms`, `v_gas_kms` (signed), `v_disk_kms`, `v_bulge_kms` (copied from SPARC; Vobs, e_Vobs, Vdisk and Vbulge are taken as absolute values) plus `default_halo` (**model**: the NFW grid fit) |
| `index.html` | The whole site, with the `galaxies.js` code and settings inlined. This is the only file deployed, together with the QR images |

**Site CSV export** (the download button; file `<galaxy>_rotation_curve_model.csv`).
The values are on a 1 kpc grid and linearly interpolated between SPARC radii,
so they are **not** the raw measurements.

| Column | Kind | Meaning |
|---|---|---|
| Radius_kpc | – | grid radius |
| V_obs, V_obs_err | observation (interpolated) | omitted for sandbox galaxies |
| V_gas | data (interpolated) | signed gas speed |
| V_stars | model | √(Υ_d V_disk² + Υ_b V_bulge²) |
| V_bar | model | √(V_gas\|V_gas\| + V_stars²) |
| V_nfw_halo | model | NFW halo speed; in MOND mode, the MOND boost √(V_MOND² − V_bar²) |
| V_total_model | model | √(V_bar² + V_nfw_halo²) |
| Residual_V_obs_minus_V_bar | derived | V_obs − V_bar |
